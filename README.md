# PlayTimeTracker

윈도우에서 실행 중인 프로그램(게임, 개발 도구 등)의 사용 시간을 **자동으로** 기록하는 트레이 프로그램입니다.

스마트폰의 스크린타임처럼, 따로 등록하지 않아도 프로그램이 켜지는 순간부터 꺼질 때까지의 시간이 쌓입니다.
"이번 주에 롤을 몇 시간 했지?", "VSCode를 하루에 얼마나 켜 두지?" 같은 질문에 바로 답할 수 있습니다.

- 기록 대상 예: 리그 오브 레전드, 붕괴: 스타레일, 문명 6, 오버워치, VSCode, IntelliJ IDEA
- 모든 기록은 내 PC 안(SQLite 파일)에만 저장되며, 인터넷으로 보내지 않습니다.
- 게임 프로세스의 메모리는 건드리지 않습니다. 프로세스 이름과 창 정보만 읽습니다.

## 설치

1. `PlayTimeTracker-Setup-<버전>.exe`를 실행합니다.
2. 설치 마법사를 따라 진행합니다. 관리자 권한은 필요 없습니다.
3. 마지막 화면에서 "PlayTimeTracker 실행"을 체크해 두면 바로 시작됩니다.

- 설치 위치: `%LOCALAPPDATA%\Programs\PlayTimeTracker` (현재 사용자에게만 설치)
- .NET이 설치 파일 안에 포함되어 있어 따로 설치할 것이 없습니다.
- 시작 메뉴에 바로가기가 생깁니다. 바탕 화면 바로가기는 설치 중에 고를 수 있습니다.
- **윈도우 시작 시 자동 실행은 하지 않습니다.** 기록하려면 직접 켜 두어야 합니다.

요구 사항: Windows 10/11 64비트

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 자동 감지 | 창이 있는 프로그램을 2초마다 확인해 켜지고 꺼지는 것을 기록합니다. 백그라운드 서비스는 기록하지 않습니다. |
| 실행 시간 / 포커스 시간 | 프로그램이 켜져 있던 시간과, 실제로 그 창을 앞에 두고 쓴 시간을 따로 셉니다. |
| 자리 비움 | 5분간 키보드·마우스 입력이 없으면 포커스 시간 집계를 멈춥니다. |
| 게임 자동 인식 | Steam·Riot·Epic 등 게임 폴더와 잘 알려진 게임 실행 파일을 보고 게임을 알아서 구분합니다. |
| 통계 | 오늘·어제·이번 주·지난주·이번 달·지난달·최근 7일/30일·전체 기간·날짜 직접 선택. 막대 그래프와 정렬. |
| 기간 비교 | 어제·지난주·지난달 또는 직접 고른 기간과 나란히 비교합니다. |
| 상세 보기 | 프로그램 하나의 날짜별 사용 시간과 실행 기록(언제 켜고 껐는지)을 봅니다. |
| 묶기 | 같은 게임의 여러 프로세스(예: 클라이언트와 게임 본체)를 태그로 묶어 하나로 셉니다. |
| 제외 / 삭제 | 메신저·오피스·런처 등 보고 싶지 않은 프로그램은 아예 감지하지 않습니다. 기록 삭제도 됩니다. |
| 사용 시간 알림 | 정한 시간마다(예: 1시간마다) 화면 오른쪽 아래에 팝업으로 알려 줍니다. |
| 작은 창 | 메인 창을 닫으면 "지금 쓰는 프로그램 - 오늘 사용 시간"을 보여 주는 작은 창을 띄울 수 있습니다. |
| 화면 설정 | 해상도에 맞춘 화면 배율, 화이트/블랙 모드. |

## 사용법

### 메인 창: 지금 실행 중

프로그램을 켜면 처음 보이는 창입니다.

- 지금 실행 중인 프로그램 목록과, 이번에 켠 뒤로의 **실행** 시간 / **포커스** 시간이 1초마다 올라갑니다.
- 지금 앞에 띄워 둔(포커스된) 프로그램은 강조되어 표시됩니다.
- 게임을 하고 있으면 위쪽에 현재 게임이 표시됩니다.
- 각 줄의 **상세 보기**로 그 프로그램의 기록을 볼 수 있습니다.
- 위쪽 버튼: **설정**, **프로그램 관리**, **통계 보기**
- 창을 닫아도 프로그램은 꺼지지 않고 트레이에서 계속 기록합니다.

### 통계

메인 창의 **통계 보기** 또는 트레이 메뉴의 **통계**로 엽니다.

- **기간**: 오늘, 어제, 이번 주, 지난주, 이번 달, 지난달, 최근 7일, 최근 30일, 전체 기간, 날짜 직접 선택
  - 날짜 직접 선택을 고르면 달력 두 개가 나타나 시작일과 끝일(포함)을 고를 수 있습니다.
  - 한 주는 **월요일 00:00**에 시작합니다.
- **비교**: 비교 안 함(기본), 어제, 지난주, 지난달, 직접 선택
  - 비교를 켜면 각 줄 아래에 회색 막대(비교 기간의 실행 시간)와 ▲▼ 증감이 표시됩니다.
  - 직접 선택은 시작일만 고르면 위에서 고른 기간과 같은 길이만큼 비교합니다.
  - 이번 기간에는 안 썼지만 비교 기간에만 쓴 프로그램도 맨 아래에 함께 보여 줍니다.
- **게임만**: 게임 관리에 들어 있는 프로그램만 봅니다.
- **▼ 많은 순 / ▲ 적은 순**: 실행 시간 기준으로 정렬합니다.
- 막대: 연한 색은 실행 시간, 진한 색은 포커스 시간입니다.
- 자정을 넘긴 기록은 날짜별로 나누어 계산합니다.

### 상세 보기

메인 창에서 프로그램 줄의 **상세 보기**를 누르면 열립니다.

- 요약: 오늘·이번 주·이번 달·전체 사용 시간
- 최근 30일의 날짜별 사용 시간
- 최근 90일의 실행 기록(시작 시각, 종료 시각, 실행/포커스 시간)

### 프로그램 관리

기록된 프로그램마다 표시 방법을 정합니다. 바꾼 뒤 **저장**을 누르면 적용되고 창이 닫힙니다.

| 칸 | 설명 |
| --- | --- |
| 표시 이름 | 목록과 통계에 보일 이름. 비워 두면 실행 파일의 제품명을 씁니다. |
| 묶음 태그 | 같은 태그를 넣은 프로그램은 하나로 합쳐 셉니다. 쉼표로 여러 개 넣을 수 있습니다. 예: `롤` |
| 알림 (시간마다) | 몇 시간마다 알림을 받을지. 예: `1`, `2`, `0.5`(30분). 비워 두면 알림 없음. |
| 게임 | 이 프로그램을 게임 관리로 옮깁니다. |
| 삭제 | 기록을 모두 지우고, 앞으로도 감지하지 않도록 제외 목록에 넣습니다. |

아래쪽 버튼:

- **제외한 프로그램도 보기**: 제외 목록에 있는 프로그램도 함께 표시합니다.
- **제외 목록**: 제외 목록 창을 엽니다.
- **게임관리**: 게임 관리 창을 엽니다.

> 묶기 예시: 리그 오브 레전드는 클라이언트(`LeagueClient.exe`)와 게임(`League of Legends.exe`)이 따로 실행됩니다.
> 두 프로그램의 묶음 태그에 모두 `롤`을 넣으면 통계에서 "롤" 한 줄로 합쳐지고, 겹치는 시간은 한 번만 셉니다.

### 게임 관리

게임으로 분류된 프로그램만 모아 둔 관리 창입니다. 칸은 프로그램 관리와 같습니다.

- 게임 폴더(Steam, Riot Games, Epic Games 등)에 있거나 잘 알려진 게임 실행 파일이면 자동으로 들어옵니다.
- 자동으로 못 알아본 게임은 프로그램 관리에서 **게임** 버튼으로 옮깁니다.
- 게임이 아닌데 들어와 있으면 **게임 해제**로 뺍니다.
- 통계의 **게임만**과 메인 창의 현재 게임 표시는 이 목록을 기준으로 합니다.

### 제외 목록

여기 있는 실행 파일 이름은 **아예 감지하지 않습니다**(기록이 남지 않음).

- 처음 설치하면 메신저(카카오톡, 라인, 디스코드 등), 오피스(엑셀, 워드 등), 게임 런처, 윈도우 기본 구성 요소가 들어 있습니다.
- **추가**: 실행 파일 이름(예: `notepad.exe`)을 넣으면 그 프로그램의 지금까지 기록도 함께 지워집니다. 기록이 있으면 먼저 확인을 묻습니다.
- **빼기**: 목록에서 빼면 바로 다시 감지되어 프로그램 관리에 나타납니다. 지워진 기록이 돌아오지는 않습니다.
- PlayTimeTracker 자신, 윈도우 폴더의 프로그램, 런처 폴더의 프로그램은 목록과 관계없이 항상 제외됩니다.

### 사용 시간 알림

1. 프로그램 관리 또는 게임 관리에서 **알림 (시간마다)** 칸에 숫자를 넣고 저장합니다.
2. 그 프로그램을 켠 뒤로 정한 시간이 지날 때마다 화면 오른쪽 아래에 팝업이 뜹니다.
   예: `1`을 넣으면 1시간째, 2시간째, 3시간째…에 "OO: 1시간째 실행 중입니다."

- 팝업은 5초 뒤 저절로 닫히고, ✕로 바로 닫을 수도 있습니다.
- 팝업은 포커스를 빼앗지 않아 게임 중에도 입력이 끊기지 않습니다.
- 여러 개가 동시에 뜨면 위로 쌓입니다.
- 묶음으로 합친 프로그램은 가장 짧은 간격을 따릅니다.
- 시간은 **이번에 켠 뒤로**의 실행 시간 기준입니다. 껐다 켜면 다시 처음부터 셉니다.
- 설정 창의 **알림 테스트**로 팝업 모양을 미리 볼 수 있습니다.
- 전체 화면 전용 모드로 실행되는 게임에서는 팝업이 가려질 수 있습니다. 테두리 없는 창 모드에서는 보입니다.

### 설정

메인 창의 **설정** 또는 트레이 메뉴의 **설정**으로 엽니다. 바꾸는 즉시 저장·적용됩니다.

- **화면 크기**: "해상도에 맞춤 (자동)" 또는 80%~200%. 모든 창의 글자와 기본 크기가 함께 바뀝니다.
  - 자동은 화면 높이 1080을 100%로 봅니다(예: 2560×1440이면 약 135%).
  - 화면보다 커지는 배율은 화면에 들어오는 크기로 줄여서 적용합니다.
  - 각 창은 테두리를 끌어 따로 늘리거나 줄일 수도 있습니다(기본 크기의 60%까지).
- **배경**: 윈도우 설정 따름 / 화이트 모드 / 블랙 모드
- **작은 창**: "메인 창을 닫으면 작은 창 띄우기"
- **알림**: 알림 테스트 버튼

### 작은 창

설정에서 켜 두면, 메인 창을 닫을 때 화면 오른쪽 아래에 작은 창이 뜹니다.

- 내용: `지금 포커스된 프로그램 이름 - 오늘 사용 시간` (묶음이 있으면 묶음 기준)
- 항상 다른 창 위에 떠 있고, Alt+Tab 목록과 작업 표시줄에는 나오지 않습니다.
- **끌기**: 원하는 위치로 옮깁니다.
- **크기 조절**: 네 변이나 오른쪽 아래 모서리를 끌거나, 마우스 휠을 돌립니다(60%~300%). 크기는 저장됩니다.
- **두 번 클릭**: 메인 창을 엽니다.
- **✕**: 작은 창만 닫습니다(기록은 계속됩니다).

### 트레이 아이콘

작업 표시줄 오른쪽 알림 영역의 아이콘입니다.

- 더블 클릭: 메인 창 열기
- 마우스를 올리면 지금 하고 있는 게임이 표시됩니다.
- 오른쪽 클릭 메뉴: 열기 / 통계 / 프로그램 관리 / 게임 관리 / 설정 / **종료**
- 프로그램을 완전히 끄려면 메뉴의 **종료**를 누릅니다. 종료할 때 진행 중인 기록을 저장합니다.

## 어떻게 기록하나요

- 2초마다 화면에 창이 있는 프로그램 목록, 지금 앞에 있는 창, 마지막 입력 시각을 확인합니다.
- 프로그램이 새로 보이면 세션을 시작하고, 사라지면 세션을 마감합니다.
  세션 하나 = (프로그램, 시작 시각, 종료 시각, 포커스 초)
- 기록은 메모리에 모았다가 **30초마다** 파일에 저장합니다. 갑자기 꺼져도 최대 30초 정도만 잃습니다.
- PC가 절전에 들어가 감지가 30초 이상 끊기면 그 앞에서 세션을 끊어, 자는 동안의 시간이 쌓이지 않게 합니다.
- 일/주/월 합계는 저장하지 않고 통계를 볼 때마다 세션에서 계산합니다.
- 표시 이름과 아이콘은 실행 파일의 제품 정보에서 가져옵니다.
- 기록은 한 번에 하나만 실행됩니다. 이미 켜져 있으면 "이미 실행 중"이라고 알려 줍니다.

## 데이터 위치와 백업

- 기록 파일: `%LOCALAPPDATA%\PlayTimeTracker\playtime.db` (SQLite)
- 설정(화면 배율, 배경, 작은 창 등)도 같은 파일에 저장됩니다.
- 백업은 PlayTimeTracker를 종료한 뒤 이 폴더를 통째로 복사하면 됩니다.
